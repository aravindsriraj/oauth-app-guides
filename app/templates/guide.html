    In the Composio dashboard, open Auth Configs and click Create Auth Config. Choose {{ g.app_name }}, pick OAuth2, and paste your Client ID and Client Secret.

  2. Check the redirect URIYou

    {{ g.app_name }}'s app settings must list exactly this URL:

    {{ c.redirect_uri }} {{ copy(c.redirect_uri) }}

  3. Use it in your sessionsAgent can do this

    Copy the auth config ID (it starts with ac_) and pass it when you create sessions:

    session = composio.create(
    user_id="user_123",
    auth_configs={"{{ c.toolkit }}": "ac_your_config_id"},
)
  4. Test the connectionYou

    Call session.authorize("{{ c.toolkit }}"), open the link, and connect your own account. The consent screen should show your app's name, not Composio's.
